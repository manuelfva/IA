# Repository Conventions

- Reuse existing implementations whenever possible
- Search before creating
- Extend before replacing
- Keep changes minimal
- Preserve repository patterns and naming
- Check for existing files and directories before creating new ones
- Check for existing solution or project files before compiling or running them

## Documentation Updates

- Do not modify `README.md` unless explicitly instructed by the user or when the project structure/contracts change (remember the `Last Updated` value must be always updated too).
- A simple code change (implementation, tests, internal fixes) does not require updating the README.
- If you are unsure, ask the user before editing the README.
